# Customer Lifetime Value (CLV) Prediction | Machine Learning

Machine learning project developed as part of an MSc Computer Science project to estimate customer lifetime value using customer demographics and usage patterns.

## Project Objective
The aim of the project is to investigate how machine learning can be used to predict Customer Lifetime Value (CLV), supporting customer segmentation, retention strategy and data-driven decision making.

## Technologies & Skills
- Python
- Pandas & NumPy
- scikit-learn
- Machine Learning
- Data preprocessing
- Exploratory data analysis
- Regression modelling
- Model evaluation

## Models Explored
- Linear Regression
- Decision Tree
- Random Forest
- AdaBoost
- XGBoost

Models were compared using regression evaluation measures including R², MSE, RMSE and MAE. Random Forest was selected as the strongest model in the project analysis.

## Repository Contents
- `Artefact.ipynb` – analysis and machine learning notebook
- `insurance-ltv-decrease.csv` – project dataset
- `Develop Models to Estimate the Lifetime Value of Customers Based on Usage Patterns and Demographics.pdf` – MSc project report
- `Presentation.pdf` – project presentation

## Project Approach
The work follows a structured analytics workflow based on CRISP-DM: understanding the business problem, understanding and preparing the data, developing candidate models, evaluating their performance and interpreting the results.

## What This Project Demonstrates
This project provides evidence of practical Python, data analysis and machine-learning experience and is particularly relevant to Data Analyst, Junior Data Scientist, Reporting/Data and graduate technology roles.
